# 567 Brand

## Position

567 is a focused dance-practice tool. The product promise is simple: class videos stop disappearing into the camera roll and become a loopable move library dancers can actually use.

The brand should feel native, direct, high-contrast, and physical. It is closer to a full-screen practice surface than a lifestyle magazine or playful learning app.

## Name

- App name: `567`
- Formal / DBA spelling when needed: `Five67`
- Retired wording: `Cumbia Moves`

## Visual System

> The current iOS implementation contract is [`design-system.md`](design-system.md). It supersedes the older blue/glow palette below for in-app UI.

567 has two visual contexts.

### Immersive Practice

Used for the iOS feed, app screenshots, video surfaces, and any marketing asset that is selling the core practice loop.

- Primary surface: near-black / black
- Foreground: white
- Secondary foreground: white at reduced opacity
- Primary action: system blue
- Ambient accent: cyan glow, used sparingly
- Secondary accent: purple glow, used only as supporting depth
- Chrome: glass, blur, translucent black, thin white strokes
- Imagery: real app video/list captures should lead

### System Utility

Used for lists, settings, library panes, exports, and web directory surfaces.

- Primary surface: system background / white
- Text: near-black
- Secondary text: muted gray
- Action: blue
- Status: green for mastered/success, orange for stuck/attention
- Shape: compact native controls and restrained cards

## Typography

- Sans-only.
- Prefer Apple system typography in native UI.
- Marketing screenshots should use bold, compact headlines with short lines.
- No serif display face.
- No decorative script.
- Use weight and scale for emphasis, not elaborate type treatments.

## Shape And Motion

- Controls should feel native: capsules, circles, compact rounded rectangles.
- App Store screenshot cards can use larger canvas-scale type, but should preserve the app's sparse control language.
- Glass surfaces should be translucent and functional, not ornamental.
- Motion language is quick, direct, and tied to physical practice: swipe, tap, loop, mark.

## Screenshot Direction

App Store screenshots should sell outcomes, not document UI.

Preferred arc:

1. Turn class videos into practice.
2. Find the move you forgot.
3. Keep dance styles organized.
4. Clip, name, and loop the useful part.
5. Your class videos finally have a home.

Use real screenshots inside device frames. Keep outside-device copy sparse, high-contrast, and readable at thumbnail size.
